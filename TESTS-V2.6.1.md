# Tests CareerPack Siham V2.6.1

## Matrice finale
- mobile portrait : 360 × 740 ;
- mobile paysage : 740 × 360 ;
- tablette : 768 × 658 ;
- ordinateur : 1280 × 720.

## Fenêtres contrôlées
- bibliothèque ;
- profil ;
- aide contextuelle ;
- assistant de candidature ;
- espace CV / lettre / message.

## Critères
- aucun contenu inaccessible en bas de fenêtre ;
- défilement interne possible jusqu’au dernier élément ;
- bouton de fermeture visible après défilement ;
- aucun scroll de la page arrière ;
- aucun débordement horizontal ;
- fermeture sans déplacement intempestif de la page ;
- CV, lettre, profil, logo, photo, horloge et parcours guidés inchangés fonctionnellement.
