# CareerPack Siham V2.6.1 — Édition finale figée

Dernière passe de stabilisation de l’édition Siham. Aucun nouveau module métier n’est ajouté.

- fenêtres secondaires limitées à la hauteur réellement disponible (`100dvh`) ;
- défilement vertical interne fiable dans la bibliothèque, le profil, l’aide guidée et le générateur ;
