# Installation CareerPack Siham V2.6.1

1. Sauvegarder la valeur actuelle de `AI_ENDPOINT` dans l’ancien `config.js`.
2. Décompresser l’archive V2.6.1.
3. Remplacer les fichiers du dépôt en conservant `.git`, `.github` et `CNAME` s’il existe.
4. Reporter l’URL `AI_ENDPOINT` dans le nouveau `config.js`.
5. Faire le commit et le push sur la branche `main`.
6. Attendre que GitHub Pages termine le build et le déploiement.
7. Fermer complètement la PWA, puis la rouvrir deux fois afin de charger le cache final.

Le Google Apps Script n’a pas changé depuis la V2.6.0.
