# Installation CareerPack Siham V2.5.4

1. Conserver la valeur actuelle de `AI_ENDPOINT` dans l'ancien `config.js`.
2. Remplacer les fichiers du dépôt par le contenu de cette archive, sans supprimer `.git`, `.github` ni `CNAME`.
3. Reporter `AI_ENDPOINT` dans le nouveau `config.js`.
4. Pousser sur GitHub et attendre la fin du déploiement Pages.
5. Fermer complètement la PWA puis la rouvrir afin de charger le cache V2.5.4.
