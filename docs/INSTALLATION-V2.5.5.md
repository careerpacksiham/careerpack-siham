# Installation CareerPack Siham V2.5.5

1. Conserver la valeur actuelle de `AI_ENDPOINT` dans `config.js`.
2. Remplacer les fichiers du dépôt par le contenu de l’archive.
3. Reporter `AI_ENDPOINT` dans le nouveau `config.js`.
4. Commit et push sur GitHub.
5. Attendre le déploiement GitHub Pages.
6. Fermer complètement la PWA puis la rouvrir afin de charger le cache V2.5.5.
