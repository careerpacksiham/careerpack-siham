# CareerPack Siham V2.1 — UTDCV

## Dossier de candidature vivant

Cette version transforme la génération ponctuelle en dossier de candidature modifiable et conservable.

### Ajouts
- édition du résumé exécutif et des compétences du CV ;
- édition complète de la lettre et du message ;
- prévisualisation mise à jour pendant la saisie ;
- sauvegarde automatique locale ;
- historique « Mes candidatures préparées » ;
- réouverture et modification d’un dossier existant ;
- suppression contrôlée d’un dossier ;
- explication CareerBrain : positionnement, correspondances, mots-clés et vérifications humaines ;
- copie directe de la lettre ;
- maintien du partage natif du message ;
- fallback autonome signalé sans bloquer le parcours ;
- cache PWA versionné V2.1.

### Stockage
Les candidatures sont enregistrées dans le stockage local du navigateur utilisé. Aucune donnée n’est envoyée vers un serveur par cette fonction.

### Limites assumées
- pas encore de synchronisation multi-appareils ;
- pas encore d’édition structurée de chaque expérience du CV ;
- le profil maître reste fourni par `assets/profile.js` ;
- l’intelligence connectée dépend toujours de la configuration de `config.js`.
